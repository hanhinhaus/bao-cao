# INHAUS Báo cáo ngày

Web app nội bộ của INHAUS Design: nhân viên gửi báo cáo tiến độ hằng ngày, quản lý giao việc và xem tổng hợp giao ban.

- Cài lên điện thoại/máy tính như app (PWA), nhắc nộp báo cáo lúc 17h.
- Dữ liệu lưu trên Supabase, đã bật phân quyền theo dòng: nhân viên chỉ xem/sửa báo cáo của mình.
